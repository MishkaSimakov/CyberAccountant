# Выбор библиотек для конвертации

Рабочий пайплайн не зависит от Docling, PyTorch и моделей разметки страниц.

| Задача | Библиотеки |
| --- | --- |
| Текст и реальные символы PDF | PyMuPDF |
| Сканы и изображения | Tesseract, OpenCV, Pillow |
| Структура XLSX и Markdown-таблицы | openpyxl, tabulate |
| Пересчёт XLSX и PDF-превью Office | LibreOffice/UNO в ограниченном локальном Docker-контейнере |

openpyxl читает уже пересчитанную рабочую копию XLSX. Пустые строки отделяют
блоки, заголовки и метаданные выводятся один раз, а столбцы берутся из ячеек листа.
Calc передаёт отображаемые значения и физические границы ячеек. Адаптер связывает
их с настоящими PDF-глифами. Геометрия ячеек используется временно; в итоговом
JSON сохраняются только нормализованные символьные боксы и позиции в Markdown.

## История сравнений

Прогоны выполнены локально на предоставленных документах. Документы не
отправлялись в сетевые API. Ниже результаты конкретных версий и настроек,
а не универсальная оценка качества библиотек.

| Решение | Проверка | Наблюдение |
| --- | --- | --- |
| Docling 2.150.0, Excel-backend | Январская ведомость | Восстановил четыре столбца. В рабочем коде заменён на прямое чтение openpyxl и вывод tabulate. |
| MarkItDown 0.1.9 | Та же ведомость | Заголовок документа стал заголовком всей таблицы; появились `Unnamed` и `NaN`. |
| PyMuPDF4LLM 2.1 | Ведомость через PDF | Таблица стала текстом. |
| PyMuPDF4LLM 2.1 с Tesseract | Карточка, PNG, DOCX через PDF | PNG прочитан; на карточке потеряны подпись и важные суммы; таблица DOCX стала текстом. |
| Docling, TableFormer V1 Accurate | Карточка, 17 столбцов | Достигнут лимит декодирования 1024; структура свёрнута в одну ячейку. |
| Docling, TableFormer V1 Fast | Та же карточка | Получено 16 столбцов со смещёнными значениями. |
| Docling, TableFormer V2 | Та же карточка | Получено 15 столбцов; пять из шести контрольных сумм не прошли проверку. |
| Docling, TableFormer V2 | Акт PNG с PSM 6 и справка DOCX | Суммы и символьные координаты сохранены. |

По приоритету корректности выбран проверенный OCR и прямой разбор XLSX.
Экспериментальный модуль, параметры выбора Docling и его зависимости удалены.
Старые результаты в `output/docling` оставлены для сравнения и не используются
рабочим скриптом. Код эксперимента доступен в истории Git, коммит `d6ba045`.
