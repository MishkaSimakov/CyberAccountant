# Готовые библиотеки для конвертации

Сравнение выполнено локально на пересчитанной январской ведомости, карточке
затрат, акте PNG и PDF-превью справки DOCX. Документы в сетевые API не отправлялись.

| Решение | Что проверено | Результат |
| --- | --- | --- |
| Docling 2.150.0, Excel-backend | XLSX после пересчёта Calc | Нашёл отдельные блоки метаданных и таблицу из четырёх столбцов. Выбран для XLSX. |
| MarkItDown 0.1.9 | Тот же XLSX | Заголовок документа стал заголовком всей таблицы; появились `Unnamed` и `NaN`. |
| PyMuPDF4LLM 2.1 | XLSX через PDF | Данные извлеклись в текст, таблица не сохранилась. |
| PyMuPDF4LLM 2.1 с Tesseract | Скан карточки, PNG-акт, DOCX через PDF | PNG-акт прочитан; на карточке потеряны подпись, структура и важные суммы; таблица DOCX стала текстом. |

Это результаты конкретных версий и настроек, а не универсальная оценка качества.
У Docling проверен Excel-backend без моделей; его нейросетевой PDF-пайплайн
в это сравнение не входил. Дополнительные модели и настройки могут изменить результат.

## Реализация

- Docling сам читает XLSX через openpyxl, выделяет области таблиц и сериализует Markdown.
- Включён только пакет `docling-slim[format-xlsx]`; загрузка моделей не требуется.
- LibreOffice/UNO пересчитывает формулы и сообщает отображаемый текст и физические
  границы ячеек из того же документа, который экспортируется в PDF.
- Небольшой адаптер `spreadsheet_layout.py` связывает ячейки Docling с настоящими
  PDF-глифами PyMuPDF и позициями в Markdown. Уникальные маркеры ячеек предотвращают
  путаницу между одинаковыми суммами в разных строках.
- Геометрия ячеек используется только при конвертации. В результатах сохраняются
  исключительно `bbox_normalized` символов; сырые ячейки не дублируются в JSON.
- Символьные области берутся из PDF, а не получаются делением области слова.
  Глифы с нулевой или отсутствующей областью не подменяются выдуманными координатами;
  сохраняется предупреждение о неполном соответствии.
- Markdown представляет значения ячеек; изображения и графики остаются в PDF-превью.
- Для сканов сохранены Tesseract, OpenCV и проверенные исправления мелких чисел
  и разрозненных подписей. Замена всего пути на другой конвертер должна сначала
  проходить те же проверки сумм, структуры и координат.
